type, public, extends(equation_solver) :: continuation_solver

Adaptive parameter continuation for square nonlinear systems. The default homotopy connects the initial guess x0 to the target system F(x)=0. Its Jacobian uses vecfcn_helper, which selects an analytic Jacobian, AD, or finite differences for the target system. A custom homotopy must satisfy H(x0,0)=0 and H(x,1)=F(x).

Fixed-parameter continuation is the default. Pseudo-arclength mode augments the corrector and can follow regular folds in the path. Extend this type and override homotopy and homotopy_jacobian to change the path without replacing the continuation algorithm.
